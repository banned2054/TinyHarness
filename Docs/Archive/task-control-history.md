## 实施顺序与验收边界

按可独立验收的纵向切片推进，每个切片包含生产接入、离线测试和必要的 NativeAOT 验证：

1. **M15.1 运行预算**：保留现有普通模型步数上限，增加包含压缩的累计模型请求数、真实启动工具数、墙钟时间和累计 token 上限。终态、事件、日志及恢复保存同一份统计。可信配置只从用户设置注入，不接受项目或模型覆盖。
2. **M15.2 安全边界控制**：宿主提供补充、暂停、继续、取消；CLI 单输入分发覆盖审批和控制。补充要求使未执行的计划失效，已执行事实保留；不打断正在执行的写入来实现暂停。
3. **M15.3 可检查工作状态**：稳定工作项 ID、用户来源、模型完成陈述与执行事实分开，沿同一日志提交和恢复；不从压缩摘要提取确定性工作项。

M16 的 Git 归因与最终验证报告不混入本阶段。真实模型、沙箱系统配置和远端操作不属于默认验收。

以上三个切片均已实施；工程验收结果见文末。真实模型对补充要求的语义遵循未验证。
