## 真实 Windows 沙箱观察

真实探针使用既有组件、专用配置和测试目录；模型传输为 mock SSE。真实 OS 结果与真实模型结果分开计数。

- **写根授权**：未批准时新文件写入拒绝；批准冻结计划后写入成功；撤销或空 Grant 计划下另一个全新文件写入再次拒绝。`icacls` 同时显示组 Modify ACE 与每根 capability SID ACE 在撤销后仍残留。拒绝来自受限 token 不再携带相应 SID，不能称为磁盘 ACE 已回收。
- **共享状态**：顺序交替的无 Grant refresh 未收敛另一授权留下的 ACE；真实双进程并发探针未执行。顺序结果不能代替并发隔离验收。
- **读边界**：早期读探针全败来自带引号绝对路径经过 argv 与 `cmd /s /c` 的转义畸变；宿主同形命令同败。改用探针支持的无空格裸路径后，普通文件、目录、自建文件读写和 `.codex` 拒读正负对照端到端通过。不得据此宣称任意带空格命令已修复。
- **deny-read 回收**：外部组件的同一 home 簿记一致流程支持回收；跨 home 或簿记外的物理 deny ACE 可能残留。簿记清空不等于物理 ACE 全部清除。
- **网络与身份**：真实 `run` 的 L3 申请批准后 `whoami` 为宿主账户，拒绝时不执行。沙箱网络申请批准后 HTTP 经命名代理得到 200，拒绝时无外联结果；Confirmed 常设信任和 Unconfirmed 回落逐次审批分别测试。HTTPS 仍受 TLS 问题限制；没有代理时 enabled 可直接联网，不能统一称为“必经代理”。
- **夹具可靠性**：旧 `%TEMP%` 父链存在历史 ACL，Grant 负对照改用已核查的干净专用父链；目标文件须唯一，既有文件的 `File.Exists` 不能证明本轮写入发生。一次首跑写探针异常未复现，根因未定。

目录段 C2 可在 OS deny 集保护；文件名或扩展名级敏感资源只由应用层文件工具识别。普通沙箱命令不逐文件解释，不能将应用层名单当作全面 OS 秘密保护。

## 独立审查与遗留

首轮审查覆盖 73 个文本文件，另两项为二进制；OCR 仅用于范围和规则解析，未调用外部审查模型。发现 High 1、Medium 6、Low 4。复查将 H1 与 M1–M6 判为关闭，其中 C2 精度问题通过文档披露收口，不表示新增了文件级 OS 隔离。复查没有独立重跑验证，测试数字引用验证报告。

四项 Low 按“记录不修”处理：工作区内冗余 `writeRoots` 仍请求 L2 且措辞不精确；Reviewer targets 与审批显示脱敏不对称；终态审计 drain 无独立超时；相对根的修订归一化依赖 CWD。另新增非阻塞措辞观察：文件工具网络行仍带“沙箱网络受限”的补语，不能由此推断文件工具在 OS 沙箱内运行。

真实 GUI、真实模型 Reviewer、真实双进程并发和物理 ACE 撤销保持未验证或未交付；后续 C2 获批读通道的部署状态以活动计划为准。本页不产生继续实施或真实环境操作授权。
