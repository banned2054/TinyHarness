# 跨项目代码风格母版

[dotnet-code-style.md](dotnet-code-style.md) 是可复制的 .NET / C# 规则母版，
不含 TinyHarness 源码路径、特定 profile 名称或某个 Agent 的个人目录。
当前母版暂存于本仓库，可以直接取出并纳入个人规则库；新项目无需依赖本仓库路径。

## 新项目接入

1. 将母版完整复制到目标项目的 `Docs/code-style.md`，保留规则与示例。
2. 检查目标项目已有约定，将必要差异写为该项目文件末尾的“项目补充”；不要覆盖原有约定。
3. 在各 Agent 实际会读取的项目指令入口添加下面的要求，路径相对目标仓库根目录。
   已有入口文件只追加相关条目，不整文件替换。

```markdown
编写、修改或整理 C# 代码前，先完整读取并遵循 Docs/code-style.md。
结合整个函数判断换行和对齐，仅处理当前任务范围，不顺带格式化无关代码。
```

一个项目内只维护一份完整正文，各 Agent 的入口都引用它。
不能假定所有 Agent 都自动读取 `AGENTS.md`，也不能把普通 Markdown 链接当作自动加载；
应在所用工具的项目指令入口明确要求读取，并实际核实该 Agent 能访问正文。
接入其他项目需在该项目获得操作授权，本模板不授权批量修改其他仓库。

## 维护

- 项目副本随其仓库版本管理，不依赖用户绝对路径、全局配置或目录链接。
- 母版更新后按需比较并合并到各项目，保留项目补充；不自动覆盖，也不要求各项目永久逐字相同。
- 本仓库的活动规则是 [Docs/code-style.md](../code-style.md)；母版用于复制，不是第二份活动项目指令。
- [TinyHarness 源码参考记录](../Archive/code-style-evidence.md) 只留在本项目，不作为通用规则传播。
